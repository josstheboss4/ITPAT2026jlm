========================================
  HOW TO USE THIS PROJECT
========================================

TO RUN THE APP (easiest — for presenting):
1. Open the "App" folder
2. Open the "DojoManager" folder inside it
3. Double-click DojoManager.exe

No Java install needed. No NetBeans needed.
Just open the app.


FOR SCHOOL / NETBEANS (source code):
1. Open NetBeans
2. File -> Open Project
3. Choose the "DojoManager" folder
   (the one with src, nbproject, etc.)
4. Press Run

OR double-click:
  DojoManager\Start Dojo Manager.bat
  (needs Java installed)

If NetBeans gives errors, still use App\DojoManager\DojoManager.exe
to show the working program.


WHERE IS THE DATABASE / TEST DATA?
================================

Those .dat files ARE the database (secondary storage).
Sample test data is already included so screens are not empty.

If you run the EXE (recommended for presenting):
  App\DojoManager\dojo_data\

If you run from NetBeans / the .bat:
  DojoManager\dojo_data\

Files in that folder:
  students.dat   - sample students (test data)
  classes.dat    - sample class timetable (test data)
  dojo_info.dat  - dojo name / address / contact
  README.txt     - short reminder of what this folder is

When you run the program, it loads from this folder and saves
any changes back into the same files automatically.
